# The Barber Company

Next.js App Router, TypeScript, Tailwind CSS 4, and Lucide React. Responsive barbershop brand concept with locally hosted fonts and photography, accessible service tabs, expandable FAQs, WhatsApp booking, Google Maps directions, and a mobile booking dock.

## Run

```sh
npm install
npm run dev
```

## Verify and build

```sh
npm run typecheck
npm run build
```

The production build exports to `out/`. Serve this directory with any static host. Webpack is selected because Turbopack's child-process port binding is restricted in this environment.
